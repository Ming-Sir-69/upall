# Roadmap

These are candidates, not enabled background work or promises.

1. Expand meaningful test coverage for channels, prereleases, duplicate installations and nonstandard wrappers.
2. Validate Chinese IME composition/candidate-window behavior in actual terminals.
3. Add an English display layer without changing Chinese-first keyboard shortcuts or JSON identifiers.
4. Consider a bounded version-check cache after measuring startup and network latency.
5. Expand actual POSIX platform validation before claiming support beyond macOS.
6. Improve update verification when a release changes between query and installation.
7. Add new adapters only with provenance-aware updates and isolated tests.
8. Introduce hosted automation or package-registry publication only after a separate decision about cost, ownership and credentials.

Default check-first behavior, stable key mapping, no unsolicited installations and no shell-layout changes remain compatibility expectations.
